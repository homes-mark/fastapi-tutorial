# FastAPI 由浅入深完整学习教程

> 一份面向 Python 开发者的中文 FastAPI 教程：从接口基础开始，逐步学习数据校验、依赖注入、异步编程、数据库、认证授权与部署，并通过一个分阶段演进的实战项目串联全部知识点。

## 这个教程是为了什么？

FastAPI 不只是“用几行代码写出一个接口”。真正投入项目后，还需要处理数据校验、依赖复用、异步并发、数据库访问、安全认证、后台任务和部署等问题。

本教程希望帮助读者：

- 建立 FastAPI 的完整知识体系，而不是只记住零散的装饰器用法；
- 理解每个核心机制解决的问题，以及它们之间的演进关系；
- 通过可运行示例和练习，把概念转化为实际编码能力；
- 从简单 CRUD 逐步完成一个接近生产环境的 API 项目。

教程不依赖在线文档或 CDN，所有页面均可离线阅读，适合系统学习、课后复习或作为项目参考。

## 教程包含哪些内容？

### 基础篇：写出第一个可靠的 API

| 章节 | 内容 | 重点 |
| --- | --- | --- |
| [01. 简介与安装](./01-basics/01-intro.html) | FastAPI 特点、环境搭建、第一个接口 | 理解 FastAPI、Uvicorn 与 OpenAPI 的基本关系 |
| [02. 路径与请求处理](./01-basics/02-path-request.html) | 路由、路径参数、查询参数、响应模型 | 掌握请求参数传递与响应数据约束 |
| [03. 请求体与 Pydantic](./01-basics/03-request-body.html) | 请求体、字段校验、数据模型 | 学会用 Pydantic 把外部输入变成可靠数据 |

### 进阶篇：组织真实项目需要的机制

| 章节 | 内容 | 重点 |
| --- | --- | --- |
| [04. 依赖注入](./02-intermediate/04-dependency.html) | `Depends`、依赖复用、依赖链 | 解耦业务逻辑并统一处理鉴权、配置等横切能力 |
| [05. 中间件](./02-intermediate/05-middleware.html) | 请求/响应钩子、日志与异常处理 | 在请求进入路由前后加入通用能力 |
| [06. 后台任务](./02-intermediate/06-background.html) | `BackgroundTasks`、异步任务 | 解耦耗时操作，避免阻塞主请求 |

| 章节 | 内容 | 重点 |
| --- | --- | --- |
| [07. 异步编程](./03-advanced/07-async.html) | `async/await`、异步 I/O、并发 | 理解 FastAPI 的高性能来源及其适用场景 |
| [08. 数据库集成](./03-advanced/08-database.html) | SQLAlchemy、Session、会话模式 | 建立可靠的数据访问与事务边界 |

| [10. WebSocket 与部署](./03-advanced/10-websocket.html) | 实时通信、生产部署与容器化 | 将接口服务从本地运行走向实际部署 |

### 实战篇：完成一个逐步演进的 API 项目

实战项目按四个阶段递进，每一阶段都会在上一阶段基础上增加新的工程能力：

1. **阶段一：单模块 CRUD**——完成用户与商品的基本增删改查；
2. **阶段二：多模块与数据库**——拆分项目结构，接入 SQLAlchemy 和数据模型；
3. **阶段三：认证与后台任务**——加入 JWT 登录、权限校验和异步任务；
4. **阶段四：企业级完善**——补充安全、测试、可维护性与部署能力。

## 学习方式

- 建议按“基础 → 进阶 → 高级 → 实战”的顺序阅读；
- 每章都包含学习目标、前置知识、代码示例、练习、常见误区与最佳实践；
- 页面顶部可标记完成，学习进度会保存在浏览器本地；
- 所有资源均为本地文件，下载仓库后直接用浏览器打开即可离线学习。

## 快速开始

克隆或下载本仓库，然后打开 [`index.html`](./index.html)：

```bash
git clone https://github.com/homes-mark/fastapi-tutorial.git
cd fastapi-tutorial
```

也可以直接双击 `index.html`，从教程首页开始。

## 适合谁？

- 刚接触 FastAPI，希望系统掌握基础与项目结构的开发者；
- 已经会写 Python，但不了解现代 API 工程化的学习者；
- 需要快速回顾依赖注入、认证、数据库或异步编程的开发者。

## 示例版本

教程示例基于 FastAPI `0.110.0`、Pydantic `2.6.4`、SQLAlchemy `2.0.29`、Uvicorn `0.29.0` 等版本。实际开发新项目时，请同时参考对应版本的官方文档，并使用环境变量或密钥管理服务保存敏感配置。

更多制作说明与项目决策记录见 [`HANDOFF.md`](./HANDOFF.md)。
